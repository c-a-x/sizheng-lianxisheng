# 思政练习生

微信小程序：思政课刷题工具。三科题库共 1097 题，全部离线可用，学习记录只存在本机。

## 功能

- **三科题库**：马原 450 题、毛中特 255 题、新思想 392 题，共 30 个章节
- **练习模式**：顺序、随机、单选专练、多选专练、章节练习、错题重练、收藏重做
- **答题页**：逐题作答、左右滑动翻页、答对自动跳下一题（可关）、断点续答
- **解析**：解题思路 + 每个选项的入选/排除依据 + 记忆小注，三科全覆盖
- **斩题**：标记已掌握的题目，不再进入组卷；可在题库「已斩」中查看与撤销
- **背题模式**：直接展示答案与解析，不记录作答
- **外观**：纯白 / 米黄 / 牛皮纸 / 护眼绿 / 夜间五档底色，字号五档，字体三档（黑体 / 宋体 / 楷体）
- **题库目录**：按章节浏览、搜索题干、按未做/错题/收藏/已斩筛选
- **数据管理**：导出 Word（错题、自选题目）、JSON 备份导出与恢复（含回滚点）

## 技术栈

微信小程序原生开发，无第三方框架、无后端服务。

- 视图：WXML + WXSS（rpx 单位、Flex 布局、CSS 变量驱动的主题令牌）
- 逻辑：原生 JavaScript
- 存储：`wx.setStorageSync` + `wx.env.USER_DATA_PATH`（导出文件）
- 主包约 1.8 MB，未使用分包

```

  annotations*.js         逐题解析与记忆小注
```

## 本地校验

```bash
node scripts/validate.js   # 数据完整性、业务逻辑、包体大小
node scripts/ui-check.js   # 页面级烟雾测试：五主题 × 五字号 × 五个页面
```

两个脚本都不依赖微信开发者工具，直接用 Node 运行。

## 题库来源

题目与标准答案来自课程练习文档（马原练习题集、毛中特学习通导出、新思想题库 HTML）。逐题解析为另行撰写，用于学习辅助。

题库与解析仅供个人复习使用，不作为课程考核依据；如涉及版权问题请联系删除。

## 开发说明

`scripts/bank/` 下保留了题库抽取脚本，源文档更新后可重新生成 `data/` 下的数据文件。这些脚本与 `docs/`、`design/` 一起在 `project.config.json` 的 `packOptions.ignore` 中排除，不会打进小程序包。
