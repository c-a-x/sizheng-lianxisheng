| 项 | 内容 |
|---|---|

## 二、技术栈

| 项 | 内容 |
|---|---|
| 框架 | 微信原生（WXML / WXSS / JS），无第三方 UI 库 |
| 页面数 | 5 个页面 + 3 个 tabBar（刷题 / 题库 / 我的） |
| 题库规模 | 1097 题（马原 450 / 毛中特 255 / 新思想 392），30 个章节；数据紧凑存储（选项文本数组 + 章节编号） |
| 外观体系 | 5 套主题（纯白 / 米黄 / 牛皮纸 / 护眼绿 / 夜间）× 5 档字号 × 3 种字体，CSS 变量 + 根节点内联 `--fs-*` |
| 主包体积 | 约 1.5 MB（限 2 MB，未分包；余量约 550 KB） |
| 基础库 | 未在 `app.json` 固定最低版本，按开发者工具默认调试；提审前建议确认后台「最低基础库版本」设置 |

## 四、已用能力与接口

| 能力 | API | 备注 |
|---|---|---|
| 本地存储 | `wx.getStorageSync` / `setStorageSync` / `removeStorageSync` | 学习记录、偏好、外观、断点 |
| 文件 | `wx.getFileSystemManager` / `wx.openDocument` / `wx.chooseMessageFile` | 备份导入导出；`chooseMessageFile` 属隐私接口，需在用户隐私保护指引中声明「选中的文件」 |
| 转发 | `wx.shareFileMessage` | 把导出的 Word / JSON 发给微信好友 |
| 分享 | 页面级 `onShareAppMessage` + `onShareTimeline` | 5 个页面均已定义（`utils/share.js` 统一文案）；未定义时右上角「转发」会置灰 |
| 界面 | `wx.setNavigationBarColor` / `wx.setTabBarStyle` / `wx.setBackgroundColor` / `wx.pageScrollTo` | 随主题联动 |
| 剪贴板 | `wx.setClipboardData` | 仅写入（复制题号 / 提示），不读取剪贴板，无需隐私声明 |

未使用：定位、相机、相册、麦克风、通讯录、手机号、`wx.login`、任何 `wx.request`。

## 七、已修问题（2026-11-23 全量排查）

| # | 问题 | 影响 | 修法 |
|---|---|---|---|
| 1 | 恢复备份丢失「已斩」 | `store.replaceState` 只写回 records/wrong/favorites/sessions，恢复后斩题记录全部消失 | 补上 `state.slashed` |
| 2 | 切换学科后旧会话复活 | 题库切学科没清 `sizheng_catalog_context_v1`，`onShow` 会把别的学科会话横幅拉回来 | 切学科时清上下文与待跳题键 |
| 3 | 斩题后离页仍触发跳题 | 420ms 定时器没存句柄，`onUnload` 清不掉，可能对已销毁页面 `setData` | 存 `this.slashTimer`，并入 `clearAutoNext` |
| 4 | 记录被清后进完成页报错 | `finishPractice` 直接读 `session.results`，会话不存在时抛 TypeError | 加空值守卫，退回首页 |
| 5 | 本地文件越攒越满 | 每次导出 Word / 备份都留新文件，10MB 上限写满后导出必定失败 | 写成功后同前缀只保留最新一份 |
| 6 | 老状态缺 `slashed` 时题库报错 | `buildCatalog` 未兜底 `state.slashed` | 默认空对象 |
| 7 | 首页续答卡片跨学科 | 马原页会显示毛中特的「继续」 | 按首题学科过滤 |
| 8 | 「我的」页标题与 tab 不一致 | 标题仍是「学习数据」 | 改为「我的」 |

验证结果：`validate.js` PASS（1097 题、主包 1.78 MB）；`ui-check.js` 45/45（新增 6 条回归：备份保留斩题、切学科清上下文、斩题定时器清理、导出/备份滚动清理、续答按学科隔离）；答题主流程脚本 7/7；备份最坏体积 379 KB（上限 2 MB）；导出 docx 的 zip 与 XML 均通过校验。

### 提审前两项优化（同日）

| 项 | 做法 | 效果 |
|---|---|---|
| 题库搜索防抖 | 输入后 200ms 再重建列表；点题、切筛选、清空、离页时立即落定 | 不再逐字重建 450 题列表，输入更跟手 |
