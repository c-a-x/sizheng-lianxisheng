## 二、阶段一：确认内容权利与发布主体

### 2.1 题库授权

源 HTML 题库带有题库提供者和制作者信息。个人学习使用与面向公众发布是两种不同场景。

发布前必须确认：

- [ ] 三个学科题库、选项与正确答案的使用权
- [ ] 允许将内容内置到微信小程序并向公众提供
- [ ] 允许通过网络传播和用户本地留存
- [ ] 如内容来自教材、教辅或校内资料，已获得教师、课程组或出版方的书面许可
- [ ] 在应用内保留来源说明，不冒充官方题库

没有明确授权时：

- 不提交公开审核；
- 仅使用微信体验版供本人或有限成员测试；
- 或替换为完全由自己编写、拥有权利的内容。

“仅供学习”字样不能替代版权授权。

### 2.2 内容准确性

- [ ] 请任课教师或课程组复核全部答案、解题思路和记忆小注
- [ ] 明确应用不是学校或考试机构的官方产品
- [ ] 名称、简介、图标不得使用“官方”“权威押题”“原题保过”等误导表述
- [ ] 不增加用户评论、题目上传、公开社区等未经审核的 UGC 功能

### 2.3 主体选择

| 主体 | 适用情况 | 风险 |
|---|---|---|
| 个人 | 本人开发、本人维护，后台实际可选类目允许 | 教育类目通常审核更严，可能被要求教育资质 |
| 学校或课程组 | 课程配套学习工具，有明确负责教师 | 需要学校批准、账号管理和内容授权 |
| 企业或教育机构 | 对外运营、后续持续更新 | 需要主体资质及与类目匹配的经营范围/许可 |

官方备案分类指引对多数教育类内容标注为“个人备案不建议选择”，部分子类目需要办学许可或事业单位资质。不要为了过审把教育题库伪装成普通工具类目；类目与实际功能不一致会被驳回，也可能导致上线后被下架。

如果个人主体无法通过教育类目审核，优先方案是改用学校或教育机构主体，而不是删除题目、隐藏核心功能或错误选择类目。

**本阶段产出：**

- [ ] 书面授权或内容自有证明
- [ ] 教师复核记录
- [ ] 最终发布主体
- [ ] 后台实际可选且与功能匹配的服务类目

## 三、阶段二：注册小程序账号

### 3.1 注册与认证

1. 打开 [微信公众平台](https://mp.weixin.qq.com/)，注册小程序账号。
2. 选择个人、学校或其他组织主体，完成邮箱激活、主体信息登记和管理员扫码验证。
3. 按主体要求完成微信认证。
4. 在小程序后台完善名称、头像、简介和服务类目。

### 3.2 基础资料

- [ ] 名称：思政练习生（以后台是否可用为准，准备 1 至 2 个备选名）
- [ ] 头像：清晰、无微信或腾讯官方标识，建议 144 × 144 px
- [ ] 简介：准确说明题库练习、错题收藏和本地备份，不超过平台字数限制
- [ ] 服务类目：与题库学习服务一致，不以过审为目的错选
- [ ] 主营类目：与核心页面功能一致
- [ ] 管理员与项目成员：只添加实际维护人员

简介建议：

> 面向课程复习的题库练习工具，提供学科与章节练习、错题重做、收藏、题目检索和本机学习记录备份。

不要使用“官方指定”“考试原题”“权威答案”等无法证明的描述。

### 3.3 获取 AppID

进入「设置 → 开发设置」获取 AppID。

- 只提供 AppID 给代码配置人员。
- 不向任何人提供 AppSecret。
- 不把管理员密码、身份证照片、短信验证码发给开发人员。
- 后台添加开发者权限时核对微信号。

**本阶段产出：**

- [ ] 正式小程序账号
- [ ] 名称与头像审核通过
- [ ] 服务类目审核通过
- [ ] 正式 AppID
- [ ] 管理员和开发者权限配置完成

## 四、阶段三：配置隐私保护与数据说明

### 4.1 当前数据清单

| 数据 | 存放位置 | 是否上传服务器 | 用途 |
|---|---|---|---|
| 题库、答案、解析 | 小程序代码包 | 否 | 离线练习 |
| 答题记录、错题、收藏 | 微信本地缓存 | 否 | 学习进度 |
| 练习断点 | 微信本地缓存 | 否 | 断点续答 |
| 学习档案 JSON | 本机临时文件，用户主动转发 | 否 | 备份和恢复 |
| 从聊天选择的 JSON | 本机读取 | 否 | 恢复学习档案 |
| Word 导出文件 | 本机临时文件，用户主动转发 | 否 | 留存试卷与解析 |
| 昵称、头像、手机号、位置 | 不收集 | 否 | 不需要 |

### 4.2 配置用户隐私保护指引

备份恢复功能使用了 `wx.chooseMessageFile`，用于读取用户主动从聊天中选择的 `.json` 文件。发布前必须在微信公众平台配置隐私保护指引。

配置步骤：

1. 登录小程序管理后台。
2. 进入「设置 → 服务内容声明 → 用户隐私保护指引」。
3. 按后台实际名称勾选与“选择文件”或“用户选中的文件”相关的信息类型。
4. 用途填写为：恢复用户主动选择的学习档案。
5. 明确说明文件仅在本机解析，不上传服务器。
6. 提交隐私指引审核，审核通过后再提交代码审核。

用途示例：

> 用于读取用户主动从微信聊天中选择的 JSON 学习档案，以恢复答题记录、错题、收藏和练习断点。文件仅在本机解析，不会上传或共享。

注意事项：

- [ ] 未声明该接口而实际调用，恢复功能可能不可用，代码审核也可能被拒。
- [ ] 提审时“是否采集用户隐私”必须按实际情况填写，不能漏报或虚报。
- [ ] 在 iOS、Android 真机测试隐私弹窗、同意、拒绝和再次触发流程。
- [ ] 应用内“学习数据”页已提示只在本机解析，不改变该文案的承诺范围。

### 4.3 数据删除

应用已提供「学习数据 → 清除全部学习记录」：

- 删除本机答题记录、错题、收藏、断点和恢复回滚点；
- 不删除用户已经发送到微信聊天中的备份文件；
- 不保留服务器副本，因为当前没有服务器。

用户导出的文件由用户自行在微信聊天中管理，应用无法远程删除。

### 4.4 后续若增加登录或云同步

只允许采用可选的微信身份云同步，不应改成强制手机号登录：

- 使用微信 OpenID 识别用户，不要求手机号、姓名、头像；
- 默认本机优先，用户主动开启同步；
- 配置数据库安全规则，确保只能读写本人数据；
- 更新隐私保护指引并增加删除云端数据入口；
- 设计多设备冲突合并和备份回滚。

**本阶段产出：**

- [ ] 隐私保护指引审核通过
- [ ] “选择文件”用途声明完成
- [ ] 真机隐私授权流程测试通过
- [ ] 清除数据与数据说明页面可正常使用

## 五、阶段四：完成小程序备案

新小程序需要完成备案后才能发布正式版本。

### 5.1 备案前置条件

- [ ] 小程序基本信息已填写
- [ ] 至少一个与服务内容匹配的类目已审核通过
- [ ] 主体负责人和小程序负责人信息准备完成
- [ ] 手机号实名且可接收核验短信
- [ ] 如涉及教育等前置审批内容，已取得对应审批文件

### 5.2 提交备案

1. 登录小程序管理后台。
2. 在首页点击「去备案」，或在「设置 → 小程序备案」进入。
3. 填写主体、负责人、小程序服务内容信息。
4. 上传主体证件和负责人证件。
5. 完成小程序负责人人脸核身。
6. 阅读并确认互联网信息服务承诺书和真实性核验单。
7. 提交平台初审。

### 5.3 审核流程

- 平台初审通常为 1 至 2 个工作日；
- 初审通过后会收到工信部短信，通常需在 24 小时内完成核验；
- 通信管理局审核通常为 1 至 20 个工作日；
- 审核时间以实际通知为准，不应向用户承诺固定上线日期。

备案通过并取得小程序备案号后，才能进入正式版本发布阶段。

- [ ] 备案申请已提交
- [ ] 工信部短信核验已完成
- [ ] 备案审核通过
- [ ] 备案主体、名称、服务内容与小程序一致

## 十二、技术交付说明

本次新增的学习数据功能：

- 导出格式：`思政练习生学习档案_YYYYMMDD_HHMMSS.json`
- 导出内容：答题记录、错题、收藏、练习断点、未交卷考试、上次考试成绩
- 导入限制：不超过 2 MB，必须是本应用生成的有效备份
- 安全处理：过滤未知题号、异常数据及危险对象键
- 恢复策略：覆盖本机记录，自动生成一次回滚快照
- 撤回策略：支持撤销上一次恢复
- 删除策略：支持清除全部本机学习记录
- 隐私策略：用户主动选择聊天文件，仅本机读取，不上传服务器

上述自动化验证已通过，但仍需在真实微信客户端完成文件选择、隐私授权、文件转发和恢复测试。
