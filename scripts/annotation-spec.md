# 392 题深度解析写作规范

## 任务性质

为每道题独立写出一份可直接展示给学生的深度解析。先自行推导，再以题目的 `answer` 为标准答案校准。不得修改标准答案；如确实发现硬事实冲突，只在 `reviewFlag` 中简短标记。

## 输出结构

输出一个 JSON 对象，键是题号字符串，值结构如下：

```json
{
  "1": {
    "solution": "先锁定题干中的时间和行为，再辨析各会议或机关的职权，2018年修宪由全国人民代表大会完成，因此对应十三届全国人大一次会议。",
    "optionAnalysis": {
      "A": "党的十八届六中全会于2016年召开，主题聚焦全面从严治党，时间和职权都不符合题干。",
      "B": "十三届全国人大一次会议在2018年3月通过宪法修正案，时间、主体和事项全部吻合。",
      "C": "十四届全国人大三次会议发生在2025年，与题干给出的2018年不符。",
      "D": "党的十九届六中全会审议的是百年奋斗重大成就和历史经验决议，并非通过宪法修正案。"
    },
    "memoryTip": "记“2018修宪靠人大”：十三届全国人大一次会议，不要与党的全会混淆。"
  }
}
```

## 字段要求

- `solution`：1—3 句完整解题思路，45—140 个汉字。写清“题眼是什么、知识关系是什么、为什么落到标准答案”，不要只复述题干或原解析。
- `optionAnalysis`：必须覆盖该题每一个选项，键与输入完全一致，不能漏项或增项。单项 25—90 个汉字。
  - 正确选项：说明它为何与题干主体、时间、概念、限定词吻合，补足对应知识点。
  - 错误选项：指出它错在哪个具体概念、主体、时间、范围或逻辑关系，必要时给出正确表述；不能只写“错误”“不符合题意”。
  - 多选题的每个正确项都要单独写出入选理由，不能只写“属于其中之一”。
  - 判断题的“对/错”两个选项都要解释原命题为何成立或不成立。
- `memoryTip`：20—70 个汉字，必须是可操作的记忆钩子，例如关键词口诀、数字分组、主体对照、易混项排除、首字串记。必须针对本题答案，不能写“多读几遍”“认真审题”等空话。避免与其他题重复。
- `reviewFlag`：可选。仅在标准答案确有明显事实冲突时写一句说明；正常题目不要输出此字段。

## 内容约束

1. 以题目自带 `explanation` 作为事实底稿，但不得整句照抄；要用自己的语言重新讲清因果关系。
2. 不得编造来源、会议届次、人物、数字或文件名称。原解析没有提供的细节，不要为了显得丰富而虚构。
3. 保持政治表述准确，使用教材和考试语境的规范表述。
4. 相邻题目的开头和句式要有变化，不能套用同一段模板。
5. 不要在解析中暴露“模型”“生成”“输入数据”等字样。
6. 输出必须是严格 JSON；不要 Markdown 代码围栏，不要注释，不要额外说明。
